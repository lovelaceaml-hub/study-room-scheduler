# LV Rooms — Prism Grid

A completely different mobile-first prototype focused on a full-day vertical resource calendar.

## Key behavior

- Persistent **Reserve Now** action.
- Reservation flow: resource → room purpose → available start → valid end → confirmation.
- Full-day vertical calendar from **10:00 AM to 11:00 PM** in **30-minute slots**.
- Time is the left column; resource columns sit side by side.
- Rooms view uses **Time | Room 1 | Room 2 | Room 3 | Room 4**.
- Every resource shows available blocks, service/unavailable blocks, or reservations with name and purpose.
- Rooms / TVs / Whiteboards toggles all reuse the same full-day calendar model.
- Sticky resource header and sticky time column support mobile scanning.

## Visual direction

Prism Architecture: dark glossy architectural glass, dimensional surfaces, moving light beams, luminous edges, polished depth, tactile controls, and restrained animated reflections.
